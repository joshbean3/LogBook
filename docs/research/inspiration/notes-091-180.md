## 2. Flows

A. Coach onboarding chat (092-100, likely starts before 091). Entry: onboarding runs as a conversation with the coach, not a form. Each coach turn = question + 3 tappable suggested answers; free text or voice also accepted. A persistent "Onboarding" pill with a progress ring sits under the avatar so the user knows a structured flow is in progress even while chatting. Side detours are allowed: 092-095 the user attaches the screen they came from (Screen Context) and asks "Summarize this"; the coach answers (explains the dashboard, says data still syncing) then steers back to the next onboarding question. 096-097 model-mode picker (Fast/Thinking/Adaptive). 098-100 voice input: record bar with timer and waveform -> "Transcribing..." -> text placed in composer to edit before send. Loading states: collapsible "Thought for 14 seconds" and named reasoning steps. Exit: X closes the coach overlay; hamburger opens drawer.

B. Coach drawer / navigation (101-102). Hamburger slides a left drawer over the chat. Fixed destinations (Onboarding progress, Health Records, Files, Check-ins), then Chats list. Empty state 101 (message + New chat pill), populated 102 (auto-titled chats, Check-in tag for coach-initiated ones, unread dots, badge count on hamburger). Settings pinned bottom.

C. Health records upload and review (103-117). From drawer -> Health Records. Empty state is the upload sheet 103 (illustrated sample docs, two upload paths, privacy line). "Add records" -> anchored menu (106: camera, library, file). After upload, list shows "Reviewing / 4 Files / Uploading..." (107) then items land in "Ready For Review" with unread dots (104), filterable by type chips (105). Nudge card at top for stale biomarkers. Tap a record -> pushed detail inside same sheet (110/111): AI summary prose + bullets with bold numbers, warning text for unrecognized pages. Biomarkers listed as Range/Value cards (112); likely extraction errors flagged in orange with Edit link (113). Per-card "..." -> remove (114) -> confirm alert (115) -> success toast (116). Header "Edit" -> bulk edit form sheet (117) with save check. Sheets vs pushes: list and upload are sheets; detail is a push inside the sheet; edit is a modal sheet; confirm is an alert; result is a toast.

D. Check-ins (128-129). Drawer -> Check-ins sheet: scheduled recurring coach nudges with toggle, next-run countdown and cadence. Sort button opens a small bottom sheet with option cards and a confirm button that names the choice. Search pill at bottom. "+" to add (not shown).

E. Older coach history (138-139). Separate captures in older style: history list with "Start new chat", long-press to Edit/Delete.

F. Home quick-add and template generator (158-171, older style). Home dashboard -> center tab "+" -> 3x3 action grid (158). Search food -> multi-select search sheet with recents (159). Generate templates -> multi-step wizard, one question per screen with option cards and disabled Continue until picked (165, 171), last step "Save and continue" with "editable later" footer. ## 3. Patterns

Layout and navigation
- Floating circular glass buttons at top corners (close, back, menu) instead of a nav bar; content scrolls under them (092, 104, 110). Related actions grouped in one capsule (flask + "+", sort + "+") (104, 128).
- Big left-aligned page title under the buttons (104, 107), small centered title for modal tools (117, 128, 165).
- Floating bottom search pill with a separate circular close (104, 129) - reachable with thumb.
- Hierarchy: coach is the hub; drawer holds destinations (101-102). Everything else opens as tall rounded sheets over it (103-129). Detail pushes inside the sheet keep context.
- Center "+" in tab bar expands into an action grid (158), with the AI entry in the middle as a glowing orb.

Cards and lists
- White cards, ~20px radius, soft shadow, on a very light grey-lavender page (112, 128). One card per item, generous 12-16px gaps.
- Two-column label/value inside a card with tiny grey labels (Range | Value) (112).
- Row anatomy: thumbnail, colored type chip, title, two grey metadata lines, chevron arrow, unread dot at far left (104, 107).
- Type chips color-coded by category, pastel fill + saturated text (104, 105, 107).
- Group by time: "Today / Yesterday", month headers (107, 159), "Ready For Review"/"Reviewing" status sections (104, 107).
- Option cards for choices: icon, bold title, one-line description; selected = black outline + check (128, 165, 171).

Color
- Neutral, near-monochrome UI: black primary buttons, white cards, grey text. Color used sparingly for meaning: orange = needs attention/possible error (110, 113, 117), green = toggles/success/biomarker count (105, 116, 128), blue = time-relative info (128) and user chat bubble (098), red = destructive (114, 115), pink = unread dot (102, 104).
- Out-of-range lab values are not alarm-colored; summary prose bolds them instead (111, 113).
- Rings on home use one hue per metric (158).

Typography
- Roughly: page title 28-30 bold; section header 20 semibold; card title 17 semibold; body 17 regular; metadata 15 grey; micro labels 13 grey (104, 111, 112). Coach messages are plain body text, no bubble, wide measure.

AI coach behavior
- Suggested replies as full-width tappable rows under each coach turn (092, 095, 096).
- Transparent thinking: "Thought for N seconds", named reasoning steps, collapsible (095, 096).
- Mode picker Fast/Thinking/Adaptive (096).
- Screen Context: attach the current screen to a question (092-093); coach explains the screen.
- Coach keeps a structured thread (onboarding) on track after detours, with visible progress pill (092-100).
- Proactive check-ins are scheduled items the user can see, toggle, sort, search (102, 128-129); chats created by them are tagged "Check-in".
- Copy, thumbs up/down and timestamp on every coach message (092).
- AI-extracted data is always reviewable and editable, and the AI flags its own likely mistakes (111-117).

Health data explained
- Summary first in plain language, then bullets with the actual numbers bolded, then the full data list (111).
- Nudge explains why ("most accurate with biomarkers updated within 6 months") before asking for action (104).
- Syncing state explained in words by the coach ("still syncing from your wearable") (095).

Feedback and states
- Empty state: one line headline, one line hint, single pill action (101). Upload empty state is an illustrated sheet with privacy reassurance (103).
- Processing: skeleton thumbnail + "Uploading..." (107), "Transcribing..." spinner (099).
- Destructive: anchored popover -> alert with plain consequences -> toast (114-116).
- Disabled primary until valid (117, 159, 165). Confirm button restates the choice (128).
- Footer reassurance that choices are editable later (171).

Motion hints
- Drawer slides over and dims content (101). "+" rotates to X when grid opens (158). Context menu lifts card and blurs background (138). Recording waveform animates (098).

Copy tone
- Warm, short, second person, plain. Coach is chatty but brief; system copy is factual ("You won't be able to add it back to this document.").

- "Screen context" chip: when opening the assistant from Plan or Progress, attach the current screen/data as a removable chip so "summarize this" or "adjust this week" just works (092-093).

- Proposed changes as reviewable cards: AI output (like extracted biomarkers) is shown as editable cards with flagged uncertain items in orange and an Edit link (111-117). Map to Claude's proposed plan edits: show each change as a card, flag ones that conflict (e.g. hard session after poor sleep), Apply / Edit / Remove per card.
- Assistant history in a left drawer with auto-titled chats, relative time, unread dot, and a tag for assistant-initiated chats (101-102).
- Scheduled check-ins list: e.g. "Sunday weekly review", "Night-before long run reminder", each a card with next-run countdown, cadence line and toggle (128-129).

Today
- Header: date with chevron for a date picker, small status pill (e.g. "Training block: Build / week 6") with dropdown (158).
- Three ring gauges in one card for readiness-type numbers once Apple Health lands (sleep, HRV vs baseline, training load), one hue each; use Columbia Blue, navy, orange for the one needing attention (158).

- Quick-add: center "+" grid for Log run, Log lift, Add to-do, Add learned, Journal entry, Ask assistant in middle (158). If keeping six tabs, put this as a floating button on Today.

Goals
- Goal set-up as a one-question-per-screen wizard with option cards (icon, title, one-line description), disabled Continue until chosen, "editable later" footer (165, 171).
- Nudge card at top when something is stale ("2 weekly goals have no check-in this week") with chips naming them and a View button (104).

Learned
- Group archive by month headers and Today/Yesterday labels (107, 159). Search pill fixed at the bottom (104, 129). Long-press entry -> Edit/Delete lifted menu (138).

Plan
- Workout template generator wizard for lift days: location/equipment, goal, then a generated session the user can edit (165, 171).
- Morning-schedule card can borrow the check-in card anatomy: title, blue "Starts in 40 min", divider, clock line with cadence, toggle (128).
- Exercise rows like biomarker cards: name, two columns (Target | Done) with small grey labels (112); bulk edit mode turns them into fields with unit suffix inside (117).

Progress
- Summary-first: one plain-language paragraph ("Mileage up 12% over 4 weeks; long run now 14 mi"), bullets with bolded numbers, then the charts and full activity list (111).
- Activity list rows with source chip (Strava, Apple Health) colored by type, two metadata lines, arrow (104).
- Filter chips row above lists (All / Runs / Lifts / Races) (104-105).
- Don't paint off-target numbers red; reserve orange for "check this" (bad GPS, missing HR, likely-wrong import) (113).

Journal
- Month-grouped list, search pill, long-press menu (107, 138). The "Remember when" card can use the dismissible nudge card style with small orange art (104).

Settings and data
- Connect Apple Health / Strava screen like the upload sheet: illustrated sample cards, primary + secondary action, privacy line with shield (103).
- Sort/filter as small bottom sheet with option cards and a confirm button naming the choice (128).
- Destructive pattern: anchored popover -> alert with plain consequences -> toast (114-116).

Onboarding
- Make onboarding a short assistant conversation with suggested answers and a progress pill, allowing side questions (092-100), or a card wizard (165, 171). Either way end with "you can change this later" (171).
