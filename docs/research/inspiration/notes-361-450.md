When parsing finishes, the same sheet changes to a success state with "Go to food log" (review and adjust) or "Dismiss". The loading state is honest (it promises a notification instead of showing a spinner), and the AI result is reviewed, not applied automatically.

## 3. Patterns

- **Layout:** one template per metric. A big central visual (ring gauge, battery, semicircle arc), a row of two equal stat tiles under it, then the AI insight, then the intraday chart, then the breakdown lists. Cards are white, about 16pt radius, with soft shadows on a light tinted background. Margins are about 16-20pt.
- **Navigation:** a floating pill tab bar with a separate round "+" button. On scroll, the tab bar shrinks to home, the ask bar and "+". Headers put actions in a single pill (share, info, more). Detail pages carry a date dropdown in the subtitle instead of a separate date bar.
- **Sheets vs pushes:** detail pages are pushes. Explainers, single-goal drill-downs and async status are sheets. Sheets can stack (367). Full-height sheets use X + gear. Short bottom sheets use one black pill CTA, plus a text button for the secondary action.
- **Charts:** threshold-banded segmented bars with labeled thresholds (367). A period/change/sparkline table for multi-horizon trends (367). Tick-ring gauges with a color gradient by band (378). Dot-matrix waffle charts for macro amounts (385/386). A diverging gradient scale for a net value that can go either way (385). Mini bars with a dotted target line (386). Slider-style contribution bars with signed, color-coded impact (448). Intraday charts with emoji or icon event markers for sleep and workouts (378, 381).
- **Numbers:** big numerals with small units ("60 ms", "86 bpm"). The status word comes right under the number ("Medium"). Signed deltas are colored (green + / red -). Copy says "left" and "over" instead of only percentages (386, 429). Every live metric shows a freshness timestamp ("Updated: 7.54 AM", "Last data point on...").
- **Color:** each metric has its own hue (stress: cool blue landscape, energy: yellow, nutrition: blue/orange/pink per macro, sleep sheet: dark navy with lavender). Orange is used for downward change and for negative contributors, so it works as a warning or highlight color. That fits Logbook's orange highlight.
- **Typography:** large bold title (~28pt), a muted date subtitle with a chevron, hero numerals ~48-60pt, section headers ~20pt bold, small grey all-caps chart labels ("TODAY'S STRESS", "ENERGY LEVEL"), ~15pt body.
- **AI coach:** (1) An insight card on every detail page: an emoji, a short headline, 3-4 lines of plain-language explanation that combines several signals (sleep hours + activity + recovery), an ellipsis, and an expand icon. A gradient border marks it as AI. (2) A global "Ask ... anything" bar with an avatar and an unread dot, always above the tab bar. (3) AI parsing results are reviewed before they're committed (449). Caveat: the copy can contradict the numbers (378: 11 vs 36), so AI text should quote the same values it sits next to.
- **Explaining health data:** an (i) on every section. Explainer sheets state the bands with exact thresholds, show the trend over several windows and name the method ("7-day rolling averages"). Drill-downs list which entries made up the number and where each came from (auto vs manual). There is a calibrating caveat when there isn't enough data yet (381).
- **States:** opt-in cards that turn into the feature in place (385 to 386). An async processing sheet becomes a success sheet in place (448 to 449). Empty or onboarding illustrations are simple grey line art.
- **Motion hints:** the sheet content swaps in place between states, the tab bar shrinks on scroll, gauges look like they animate (tick rings), and confetti marks the ready state.
- **Copy tone:** warm, second person, encouraging but specific ("It's great to see...", "keep tonight quiet"). Titles are short and descriptive.
