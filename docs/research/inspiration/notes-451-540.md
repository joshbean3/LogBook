## 3. Patterns

Layout and navigation
- Very light grey-lavender page background, white rounded cards (~16-20pt radius), soft shadows; 16-20pt side gutters; 8-12pt gaps between cards (all).
- Floating bottom chrome: capsule tab bar + separate round + button, with an "Ask [coach] anything" bar stacked above it (496, 501, 509). On scroll it condenses to Home circle + Ask bar + plus circle (497-500). Variant capsule with raised center + (515, 520, 538).
- Detail content opens as sheets (grabber or X), not pushes; sheets stack (506 over 502). Pushed pages use a floating round back button and grouped round icon buttons (496).
- Collapsing nav: large title/header shrinks to centered small title + subtitle on scroll (463, 473, 498, 513).
- Date as page title with dropdown chevron to change the day ("Today, 14 September v") (496, 515, 520, 527).
- Horizontal day strips: tall capsule cells, weekday letter + date + status circle, today in blue, marker triangle (496, 497, 509, 538).

Cards and states
- Metric card shell: grey icon + label + arrow top row, big number with small unit, status word in color, mini chart right (471, 499, 501). Same shell for empty state ("No data / Unavailable" + dotted line) so nothing jumps (499).
- Vitals tile with a vertical "where you sit in your normal range" pill and status word (517).
- Status words over raw numbers: Above normal, Within baseline, Deficit, Normal, Irregular, Short, Low (471, 472, 477, 498, 501, 517). Normal range shown next to value ("41 - 73") (472).
- Dashed-border empty rows for "Add X" (498, 500, 517).
- Disabled grey CTA until valid, turns black (459, 488, 503/504, 506/507, 510/511).
- Selection: dark outline + check badge (504), outlined row + check (511), raised white segment (507).
- Numbered instruction cards with huge faint numerals and small illustrations (458, 460).

Charts and data viz
- Big value + date on left, status/context on right, sibling-metric chips, chart, then range segmented control flanked by prev/next arrows and a calendar button (472, 474, 477, 512).
- Average line as dotted line with a pill label "Avg. 57" (472); normal range as soft fill band (472); glowing dot on the latest point (472, 501, 512).
- Raw data as faint bars behind a smoothed line, legend explains both (512).
- Background color bands for phases/periods behind the line (512) - transferable to training blocks.
- Thin mint strip under x-axis showing days with data (472, 474, 477).
- Trends analysis table: 3/7/14/30/90-day change with arrow and sparkline; dashes when insufficient data; footnote on method (473).
- Contributor rows with previous-vs-now slider and signed delta (463); gradient score bars x/100 (464, 466).

Typography and color
- One bold sans; huge numerals (~40-48pt) for headline values, ~22-28pt titles, 15-17pt body, 12-13pt grey meta. Grey eyebrow above title (458, 467, 479).
- Mostly monochrome UI (black CTAs, grey text) with color reserved for data and status: orange = deficit/negative/warning, green = good, blue = above/lower info, violet = brand/score.
- Soft rainbow/gradient glow marks AI content (466, 470, 516, 520).

AI coach
- Appears as (1) inline insight card with gradient border, emoji + headline + 3-4 line paragraph, expand icon (496, 509, 516, 527); (2) a floating pill that the card collapses into on scroll and that persists on the page, with a mascot avatar peeking above (463-477, 512-514); (3) persistent "Ask anything" bar with unread dot (497).
- Text is personal and cross-domain: cites specific numbers from sleep, strength, walks, cycle day in one paragraph (497, 509). Regenerates right after a new log (509). Past days get past-tense recaps (527). References earlier chats (519). Ends with a gentle suggested action (512).
- Headlines are short, positive, specific ("Healthy fats, steady fuel", "Follicular temperatures are steady").

Health data explanation
- (i) explainers at the end of every metric page: what it is, why it matters, how the app computes it, a note with citations (473, 476, 514). Glossary sheet with bold term + definition (467).
- Footnotes on data basis: "Based on your past 1 year", "Based on 7-day rolling averages", "Last data point on...", "data is delayed by three hours" (461, 473, 498, 513).
- Resources carousel of short articles (513).
- Copy tone: plain, calm, encouraging, never alarmist; short labels.

Motion hints
- Card-to-pill collapse on scroll, chrome condensing on scroll, sheet stacking, glow animation on AI pill, chips switching chart in place.

## 4. Ideas for Logbook

Today
- Make the date the page title with a dropdown to view past days; past days show a recap (520, 527).
- Day strip under the header: 7 capsule cells with a completion circle per day (yellow partial, green full, today raised) driven by the habit buttons (538).
- Habit buttons: support auto-detected habits from Apple Health/Strava (steps, run minutes, zone-2, sleep) showing live value + progress ring, marked with a sparkle "auto" icon; manual ones stay tap toggles (538, 539). Add "Copy from yesterday" (539).
- Assistant: inline daily insight card with Columbia Blue gradient border, emoji + headline + 3 lines citing yesterday's run, lift, sleep; expand to full text (496, 509, 520). The ask bar sits floating above the tab bar and condenses on scroll (496, 497).
- A small status chip ("Training", "Taper", "Sick", "Travel") that changes how plan and assistant behave (520).
- Edit mode for Today sections: remove, reorder, add card, reset to default, Cancel/Save (516, 517, 519).

Plan
- Week strip as capsule day cells with a planned/done marker; color band under the strip for training block phase (base/build/taper/race week) like the cycle phase band (496, 497).
- Logging a run or lift: small stacked sheet with a big value label, segmented effort picker, time row, disabled-until-valid "Add" (506, 507); multi-select grid for lift accessories or soreness (503, 504).
- Morning-schedule card can reuse the "today card + round +" pattern (496).

Progress
- Trend cards: label + arrow, big number + unit, status word (Above normal / Within baseline), sparkline with glowing end dot; identical empty shell "No data yet" (471, 499, 501).
- Trend detail sheet: chips to switch mileage / pace / HRV / resting HR without closing; Avg pill line, normal band, faint daily bars behind a smoothed line, training-block background bands; 7D/1M/3M/6M + prev/next + calendar (472, 474, 477, 512).
- Trends Analysis table (3/7/14/30/90-day change with arrows) and weekly history table grouped by month, Avg/Total toggle (473, 475, 477).
- Health vitals grid (RHR, HRV, sleep) with the vertical normal-range pill (517).
- Explainer at the bottom of each metric: what, why, how computed, data delay footnote (461, 476, 514).
- Strava/activity detail: stat tile grid + contributors with signed deltas + AI pill that collapses on scroll (462, 463).

Goals
- Status words and normal ranges rather than raw percentages; dashed "Add goal" empty rows (498, 500).
- Progress rings in a row for week/month/year goals (516).

Learned
- Month-grouped archive as headers + cards (475). Resources-style horizontal carousel for highlighted past learnings (513).

Journal
- "Remember when" could use the share-card / sticker card treatment, with a Share sheet (save/copy/share) for a run summary or a memory (528, 529).
- Entries list rows with icon tile + time + value (502, 505, 515).

Assistant
- Three surfaces: inline card, floating collapsible pill per page with a page-specific headline, persistent ask bar (463, 472, 497). Regenerate the Today insight right after the user logs something (509). Proposed changes could appear as a card with headline + explanation + apply button in the same style.

Settings / Health connection
- Integration setup as a paged sheet with segmented progress, numbered illustrated steps, failure sheet with exact fix checklist, and a manage screen with Disconnect + data-delay footnote (458-461).

Onboarding
- Welcome hero per feature: eyebrow + title + one sentence + one strong visual + Next pill (479). Backfill step with calendar and "I don't remember" skip (488, 489).
