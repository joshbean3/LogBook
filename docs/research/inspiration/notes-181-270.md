## 3. Patterns

Layout / navigation
- Everything task-like is a modal sheet stacked on the previous one (207, 213, 248, 264, 265, 266 keypad, 267, 270). Sheet header grammar is consistent: X or Cancel left, small centered grey title, confirm (Add/check) right or a big bottom pill.
- One dominant primary action per screen: full-width near-black pill at bottom (258, 261, 264, 265); disabled = mid-grey (207, 248). Secondary actions are white pills side by side (261).
- Destructive and stop actions use a soft red/orange tint circle, never solid red (249 trash, 261 trash, 263 end X, 266 Finish).
- Collapsing large title into compact centered header on scroll (261 -> 262).
- Floating pills: toast at top for background status (260, 261), mini-player at bottom for the live activity (263).

Cards and data
- Stat grid: two columns, grey label above, large bold number, small unit suffix (261/262). Very readable.
- Score ring with number plus plain-English meaning ("6 — Little physical demand", 261). Numbers are always paired with a sentence.
- Tables in cards with pill-shaped value cells; completed rows tinted green with a check (263, 266). Warm-up sets marked with a flame icon (263, 265).
- Rest time shown as small chips between sets on a hairline, live countdown chip inverted to black (266). Good "timeline within a list" idea.

Data viz / input
- RPE arc dial with gradient blue->yellow->orange, glowing center number, label + description that change live (258-259). Color temperature = intensity.
- Skeuomorphic but restrained plate calculator: a real barbell drawing, plate colors by size (267, 270).
- Custom numeric keypad with domain helpers (stepper, plate calc, fill-from-previous) instead of the system keyboard (266).

Typography / spacing / color
- Large bold titles (~28px) for the object name, ~17px semibold section titles, ~15px grey helper text. Monospaced or tabular large timer digits (266).
- Generous white space, hairline dividers between form sections (207), 16-20px side gutters, 12-16px card radii, pill radii for buttons and inputs.
- Palette mostly white/off-white with grey surfaces; color reserved for meaning: green = done, orange = effort/finish/warm-up, blue = currently editing, red tint = delete. Faint warm radial glow at the bottom of full-screen moments (258-260).

Motion hints
- Toast morphing from "Syncing..." to green "Sync Complete" (260 -> 261); confetti and emoji on completion (261); number glow changes as dial moves (258-259); marquee scrolling for long titles (266); live countdown chip (266).

Copy tone
- Short, direct, plain: "How was the workout?", "Tiring — Exerting; heavy breathing, hard to talk.", "No previously recorded workout", "Tap plates to remove". Warnings state the consequence ("Exiting will discard the workout", 260). Forms tell you what to include before you type (248).

AI coach / health data
- No AI coach surface appears in this range. Health data appears only as live heart rate in the mini-player (263) and computed strain/energy on the summary (261). Effort scale is explained in words at every step (258-259, 261).

## 4. Ideas for Logbook

Today
- Floating "now" pill when a run or lift session is in progress, showing current block, timer and (later) heart rate from Apple Health; tap to reopen the session (263).
- Top toast pill for background work (Strava/Health sync, assistant applying a change): spinner -> green check (260-261).
- Habit buttons: completed state as pale green tint + check, like completed sets (263, 266).

Plan (training week)
- Lift session logger as a sheet: per exercise SET/KG/REPS rows, warm-up flagged with a small icon, play/check per set, rest chips between sets with a live countdown (263, 266).
- "Previous" half sheet showing last time's numbers for that lift, with a skeleton empty state when there is none (264-265).
- Numeric keypad with +/- stepper and "same as last" fill; optional plate calculator with a plate inventory setting (266-267, 270). Keep units in lb or kg per settings.
- Custom exercise form: name, copy-from-existing, equipment, rep vs duration toggle, muscles; Save disabled until valid; new items pinned under "Custom" in the exercise picker with search and filter chips (207, 213).
- After a session: "Update plan" secondary button to write today's changes back into the week's template (261).

Progress
- Session summary page: big title + date, effort ring with one-line meaning, 2-column stat grid (duration, distance/volume, reps, energy), then per-exercise tables; header collapses on scroll (261-262).
- Use orange (the new highlight) only for effort/intensity and for the single most important number; green-ish or navy check for done; Columbia Blue for selected/editing cells (266 blue edit state maps nicely to #B9D9EB).
- Link "Progression" from each lift to a trend chart (266 footer).

Journal
- After each run or lift, a one-question RPE check-in with a 1-10 arc dial (blue -> orange gradient fits the palette), live label and plain description; save the score and an optional note into that day's journal entry (258-259).

Goals
- Celebrate completions (goal hit, week complete) with a short confetti moment and a summary card, then a single Done (261).

Learned
- Reuse the sheet grammar (X left, centered title, disabled-until-valid primary pill) for the daily "what I learned" entry; tell the user what a good entry contains above the field, like the report form (248).

Assistant
- When the assistant proposes a change, present it as a sheet with a clear primary "Apply" and a secondary "Not now"; show progress as a top toast and confirm with a check (260-261 pattern). Pair any number it cites with a plain sentence (261 strain label).

Settings
- "Report a problem" form with checklist, text field, optional screenshot via Camera/Photos, preview with delete/replace (248-249).
- Equipment preferences (available plates, double-sided machines, kg/lb) as a simple toggle + checkbox list (270).

Onboarding
- Nothing onboarding-related in this range (likely in the missing numbers).
