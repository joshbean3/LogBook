## 3. Patterns

Layout and navigation
- Home is one long scroll of stacked cards under a big date title with a dropdown chevron ("Today, September 2 v") for jumping days (018, 023).
- Context chips under the title: an activity status chip ("Active - Until changed") and a weather chip (023).
- Navigation chrome is light: round floating buttons (Home, +) instead of a heavy tab bar in 023; round icon buttons in the chat header (069). In 081 a 5-icon bar is visible.
- Nearly every task is a bottom sheet; sheets stack (049, 062), and detail edits push inside the sheet with a back chevron (058-059). Sticky bottom CTA area in every sheet (029, 058, 060).

Cards and controls
- White rounded cards (~20px radius) on very light grey (#F5F5F8-ish) background, soft shadows, hairline dividers; card footers with split actions (Remove | Edit) (029).
- Primary CTA: full-width near-black pill, white text, sometimes with arrow (001, 065-068). Secondary: light grey pill with coloured text (058 Remove). Disabled: mid-grey (015, 048).
- Selector pills with chevrons for values (servings, date) and separate square -/+ steppers (059).
- Dashed outline "Add ..." row at end of lists (058).
- Toasts as small floating pills at top, often merging with the header ("Sync Complete" 023, "Message copied" 082, "Thanks for the feedback!" 085).

Charts and data viz
- Three ring gauges side by side as the day's summary (Strain, Recovery, Sleep), with "-%" for no data (018, 023).
- Tick-mark dial gauge for stress with a colour gradient on the ticks (023); segmented tick bar for energy with % at right (023, 081).
- Macro donut with a segment per macro and the total in the centre; macro columns with matching coloured labels (059).
- Consistent macro colour coding everywhere: protein blue, carbs orange, fat pink, each with a small glyph (029, 059, 064, 080).
- Nutrition-label table with heavy rules for the full detail (061).
- Empty states keep the full layout and show dashes rather than hiding the chart (023).

Typography and spacing
- One sans family. Large bold page titles (~28-34pt), section headers ~20pt semibold ("Stress & Energy"), body 17pt with relaxed line height in chat, grey secondary text ~15pt. Numbers big and bold, units small.
- Generous 20-24px side margins; ~12-16px gaps between cards; big tap targets.

Colour
- Neutral base (white, light grey, near-black text). Colour only for meaning: green for live/OK and sync, orange for strain/energy and the action accent, red for destructive (trash, Remove), blue for user chat bubbles and verified badges, macro colours. Coach screens add a soft gradient wash tinted by the chosen personality (lavender, peach) (065-072).

Motion hints
- Carousel with neighbours peeking (067-068); spinner inside the title pill while working (074, 090); collapsible "Thought for N seconds" (074); floating scroll-to-bottom arrow (074, 079); glowing composer edge (081); blurred, scaled-back Home behind the overlay (081).

Copy tone
- Short, warm, second person; first-name greetings ("How are you feeling, Alex?"). Helpful hints inside placeholders ("e.g. breakfast waffles with 2 eggs"). Errors are plain ("We couldn't load this right now. Please check your connection and try again.").

How the AI coach looks and behaves
- Has a face: a soft glowing avatar whose personality sets tone, colours and greeting (067-072). Personality shown as a sample sentence plus 3 trait chips.
- Assistant text is plain text on the page (no bubble); the user's messages are blue pills; images and files appear as their own cards (074, 088, 090).
- Shows its work: "Thought for N seconds" with a step timeline using icons per step type; steps can be the result data (food items with kcal) (074, 078-080).
- Acts, then shows the created object as a tappable card (check-in with schedule, workout with "8 exercises, 18 sets") (078-079); for logging, it stages a cart and the user taps Review cart to commit (080).
- Suggested replies as full-width first-person sentences, regenerated each turn (069, 075, 089).
- Composer: "+" (photos, files, check-in, screen context, log food), mode pill ("Adaptive"), mic, send that becomes stop (069, 086, 090).
- Each answer has copy / thumbs up / thumbs down and a timestamp; actions confirm with a toast (074, 082, 085).
- Asks for settings when relevant ("Keep thinking expanded?" 076), handles errors inline with Retry (077), defers off-topic questions politely (074).
- Quick-ask overlay over Home for short questions, expand for full chat (081).

How health data is explained
- The coach ties advice to specific recent events and states ("the Indoor Walk you did yesterday", "Cardio Load ... 'Overtraining'") and gives a concrete next step ("lighter low aerobic work for a day or two") (081).
- Detail cards show highest / lowest / average and "Last updated at 5:04 PM" (023).
- Info (i) icons next to section titles (059); the full nutrition label is one tap from the summary (061).

- Under the title, two small chips: a training status chip (e.g. "Build week - Long run day", tap to change) and weather for the run (023).

- The ask bar opens a quick-ask overlay over Today with Today blurred behind; an expand icon goes to the full assistant (081).
- Async jobs (Strava sync, Health import) show a small "Sync complete" pill (023).

Goals
- Use the card + split footer pattern for each goal (Edit | Done) and a dashed "Add goal" row at the end of each level list (029, 058).
- Goal progress as a small ring or tick bar on each card, coloured orange as the highlight (023, 059).
- Let the assistant create a goal and return it as an object card the user taps to accept (078-079).

Learned
- One-line "What did you learn today?" sheet with a placeholder example ("e.g. Cadence over 175 made my easy run feel easier"), like the food describe sheet (015).
- Archive by month as cards; date wheel picker to log for a missed day (062-063).

Plan
- Workouts the assistant builds appear as cards: icon tile, title, "6 exercises, 18 sets" or "8 mi easy - Z2", chevron to open (079).
- Editing a lift: pushed screen inside the sheet with sets as rows, a -/+ stepper, sticky Remove/Save (058-059).
- Recurring items (morning schedule) shown like the check-in card: title, description, divider, "Every weekday at 6:00 AM" (078).

Progress
- Stat cards with Highest / Lowest / Average and "Last updated" (023).
- One fixed colour per metric used everywhere (miles, HRV, resting HR, sleep), like the macro colours (029, 059, 080).
- Tick bar or dial for a single "readiness" number; totals as a donut with the number in the centre (023, 059).
- A full-detail table one tap from a summary, like the nutrition label (061) - e.g. weekly mileage breakdown.

Journal
- The "Remember when" card can borrow the coach home layout: date in small grey, one large question or memory line, a row of swipeable starter cards (Write about today's run, Add a photo) (071-072).
- Photo and file attachments staged in the composer as thumbnails with an x (087, 089).

Assistant (Claude)

- Show a collapsible "Thought for N s" step list with icons, where steps can show concrete results ("Moved Thu tempo to Fri", "Added 4x800 m") (074, 078-080).
- Answers cite the user's own data and give one concrete next step (081).
- First-person suggested replies as full-width rows (069, 075).
- "+" sheet: Photo, File, Add to plan, Log a learning, Journal entry (086). Send turns into stop while working (090). Copy / thumbs / time under each answer with toast confirmations (074, 082, 085).
- Inline error with Retry; never lose the conversation (077).
- Chat history behind a hamburger with a count badge; conversation title pill in the header with a spinner while working (069, 080, 085).

Settings
- Ask for a preference in context the first time it matters, then say "You can change this later in Settings" (076).
- Optional assistant tone setting shown as a sample sentence plus three trait chips, e.g. "Coach" (direct) vs "Steady" (protective about recovery) (067-068).

Onboarding

- Capability list: illustration + bold title + one grey line, sticky Continue (066).
