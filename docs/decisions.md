## 2026-10-31

- **Deploy from a verified commit, never from a mid-build tree.** The deploy ref is a verified commit of the working branch (this session's GitHub access is scoped to that one branch, so no separate deploy branch or tag). Round-1 verified: `8660227` plus the Strava gate. Round-2 work (accounts, backups, the worker, the COROS client) deploys once verified the same way. Runbook: `docs/deploy-v5.md`.
- **Nothing from Strava reaches a model.** Strava's API Policy effective 1 June 2026 (§5.3, §5.5, §5.10) bars Strava Data "directly or indirectly" from the operation of any AI application, names ingestion into a context window, and bars disclosure to AI providers even with the athlete's consent. First party and inference only do not help. Implemented as `apps/api/src/services/ai-sources.ts`, applied to the assistant's context and tools, the week snapshot it reads, the coach's read and the plan builder. The athlete still sees every Strava run (§2.3). Source: https://www.strava.com/legal/api_policy.
- **Strava is display only; it is not the pipe to scale on.** Default apps are capped at 10 athletes, the next tier at 9,999, a Strava subscription is required to create an app, and §5.16 bars aggregators and intermediaries. Source: https://www.strava.com/legal/api and https://developers.strava.com/docs/getting-started/.
- **COROS connects through its MCP server, with no application.** The live server publishes OAuth metadata: issuer `https://mcpus.coros.com` (regional: mcpeu, mcpcn), `/oauth2/authorize`, `/oauth2/token`, `/oauth2/device_authorization`, `/oauth2/revoke`, dynamic client registration at `/connect/register`, PKCE S256, scopes `openid mcp.tools offline_access`; access tokens 30 days, refresh 180 days, rotating. COROS built it for AI clients, so its data may be read by the assistant. The Partner API (client credentials from api@coros.com) is for established platforms and is not needed for launch. Sources: https://github.com/coroslab/COROS-MCP and the server's `/.well-known/oauth-authorization-server`.
- **Apple Developer Program is on the owner's critical path.** Needed for APNs (the `.p8` key, downloadable once; Key ID and Team ID) and TestFlight. Individual enrolment is $99/year with a 24 to 48 hour check. Until then iPhone reminders work only as an installed web app through Web Push. Source: https://developer.apple.com/help/account/keys/create-a-private-key/.
- **The database stays SQLite on one machine, with continuous backup.** The server has about 430 synchronous database calls; a Postgres move is its own project and would destabilise a fresh rebuild. Litestream replication, nightly logical backups, a health check that touches the database and a leased worker make one machine safe. Revisit when a second machine is needed.
- **Four tabs, one language.** Progress folds into Plan; Reads, the quote library and the garden leave. The contract is `docs/system.md`.
